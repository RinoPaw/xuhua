# 叙华知识库审计与检索基线

> 数据版本：仓库内 `data/source/heritage_source.json` 与 `data/processed/heritage_items.json`，2026-10-26 首次审计。工具与结果均可通过 GitHub Actions 重现。这里统计的是**按申报地区或单位区分的子项记录**。

## 口径与外部依据

中国非物质文化遗产网的国家级代表性项目名录页面说明：1557 个国家级代表性项目、3610 个地域/申报单位子项，分为 10 个类别。相同项目在不同地区的记录有可能反映不同的特征、传承与保护单位，不能只凭同名去重。

官方页面：https://www.ihchina.cn/project.html?tid=2

本地知识库有 3610 个子项、3038 个不同**展示名称**、330 组重复名称。3038 不是“国家级项目数”，也不能用于替代官方的 1557。

## 可复现实测（GitHub Actions / Ubuntu）

运行方法：

```powershell
uv run python tools/audit_heritage.py --strict
uv run python tools/evaluate_retrieval.py
```

- 原始 JSON：3610 条；运行知识库：3610 条，10 类。
- 重新执行 `tools/build_dataset.py` 的内存构建过程后，与仓库已提交的完整运行数据**完全一致**，差异记录数 0。
- ID / 标题 / 类别 / 摘要 / 正文 / 检索字段：空值数均为 0；按类别汇总与声明值一致。
- 缺少解析出的省份：90 条；缺少市：1498 条；缺少区县：1369 条。这里的“缺少”仅表示对应标准化字段为空，并不表示原始记录没有“申报地区或单位”字段。
- 原始记录均具有 `id`、`project_num`、`rx_time`，但根级来源名称、采集日期、逐条来源 URL 尚未记录。这是当前**数据来源可追溯性缺口**，不应虚构抓取日期。
- 发现 1 组同名且省市区一致的记录：“人参炮制技艺”，吉林省通化市。须比较官方项目编号和保护单位后，才能判断是否重复。

### 为什么没有自动补全 90 条省份

原始“申报地区或单位”中有“中国艺术研究院”“中国国家京剧院”“新疆生产建设兵团”“新疆师范大学”等机构名称。省份标准化不能凭机构常识、字符串子串或未经验证的编码猜测。保留原始字段及子项 ID，等待官方记录核对。

## 检索回归基线

`tools/evaluate_retrieval.py` 从十个类别各选取 3 个**名称唯一、含省份的子项**，用源数据项目名称构造查询，检索时禁用拼音扩展：

| 测试条件 | 前 1 命中 | 前 5 命中 | 前 5 MRR |
| --- | ---: | ---: | ---: |
| 项目精确名称 | 29 / 30 | 30 / 30 | 0.9833 |
| 项目精确名称 + 省份条件 | 30 / 30 | 30 / 30 | 1.0000 |

这属于从知识库自身构建的功能回归样本。**不能将 100% 的前五命中率称为真实用户问题检索准确率，也不能据此推断回答可信度。** 目前尚缺独立标注的自然语言问句、ASR 真实音频评测、事实正确率和教育场景用户任务数据。

## 下一轮技术任务

1. 对上述 90 条单位信息与 1 组同名地域碰撞核对官方项目编号，修正能确认的标准化映射，保留原始文字。
2. 为原始数据建立含来源 URL、采集时间、采集方法、原始内容散列的可信元数据；不能追溯的内容明确标为未知。
3. 建立由人工独立标注的中/英/日/韩真实问题集，测量检索 Recall@5、回答证据一致性、语音错误率和失败处理表现。
4. 将数据审计继续保持为 CI 的结构性门禁；警告类指标由人工判断，不强行修改合法的跨地域子项。

目前审计不访问外网、不调用大模型，也不会更改运行数据。
